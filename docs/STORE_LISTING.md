## 3. Google Play Console 定期購入 ＆ RevenueCat 設定シート

> ⚠️ Google Play Console で定期購入を作成する前に、まず **本番またはクローズドテスト用の AAB（`com.garanapop.coupleswipeapp`）を1回アップロード** する必要があります（Billing 権限を含むビルドを1回認識させるため）。

### 3-1. Google Play Console ＞ 収益化 ＞ 商品 ＞ 定期購入
以下の **2 商品** を作成し、それぞれ基本プランを有効化します：

| 項目 | 年額プラン（おすすめ） | 月額プラン |
|---|---|---|
| 商品 ID（Product ID） | `couple_swipe_yearly` | `couple_swipe_monthly` |
| 名前 | ふたりプレミアム（年額） | ふたりプレミアム（月額） |
| 基本プラン ID（Base Plan ID） | `yearly-base` | `monthly-base` |
| 請求期間 | 1 年 | 1 か月 |
| 更新タイプ | 自動更新 | 自動更新 |
| 価格（日本 JPY・税込） | **¥3,000** | **¥500** |
| 猶予期間（Grace Period） | 3 日〜7 日推奨 | 3 日〜7 日推奨 |
| アカウントの一時停止 | 推奨設定（30 日） | 推奨設定（30 日） |

### 3-2. RevenueCat ダッシュボード設定
1. **Project 作成** → **Apps & providers ＞ + New ＞ Google Play**
   - Package Name: `com.garanapop.coupleswipeapp`
   - Google Play サービスアカウント JSON をアップロード（Google Cloud で Play Developer API を有効化し、Play Console の「ユーザーと権限」で財務・アプリ情報参照権限を付与）
2. **Products** に Google Play から以下をインポート：
   - `couple_swipe_yearly:yearly-base`
   - `couple_swipe_monthly:monthly-base`
3. **Entitlements** に Identifier: `premium` を作成し、上記2商品を両方 Attach
4. **Offerings** の `default`（Current に設定）へ以下を紐づけ：
   - `$rc_annual` → `couple_swipe_yearly:yearly-base`
   - `$rc_monthly` → `couple_swipe_monthly:monthly-base`
5. **Project Settings ＞ API Keys** から以下2つを取得：
   - **Public API Key (Google)**: `goog_...` → EAS 環境変数 `EXPO_PUBLIC_REVENUECAT_ANDROID_KEY` へ登録
   - **Secret API Key (V1)**: `sk_...` → Supabase Edge Function Secret `REVENUECAT_SECRET_API_KEY` へ登録（購入直後の即時反映 `sync-subscription` および `TRANSFER` 同期で使用）
6. **Integrations ＞ Webhooks ＞ + New**
   - **Webhook URL**: `https://zfnbyxntyxgmoebvvifu.supabase.co/functions/v1/revenuecat-webhook`
   - **Authorization header value**: `Bearer <任意の強力なランダム文字列>`
   - 同じランダム文字列（`Bearer ` を除いた値）を Supabase Edge Function Secret `REVENUECAT_WEBHOOK_AUTH_KEY` へ登録
   - **Send test event** で **`200 OK`** を確認！

### 3-3. EAS 環境変数登録コマンド（キー取得後に実行）
```bash
npx eas-cli@latest env:create --name EXPO_PUBLIC_REVENUECAT_ANDROID_KEY --value "goog_xxxxxxxx" --visibility plaintext --environment development --environment preview --environment production
```

### 3-4. 課金テスト手順（Google Play ライセンステスト）
1. Google Play Console ＞ **設定 ＞ ライセンステスト** にテスト用 Gmail アカウントを追加（レスポンス: `RESPOND_NORMALLY`）
2. クローズドテスト（または内部テスト）トラックへ AAB をアップロードし、テストアカウントで Play ストア経由インストール
3. テストカード（「テストカード、常に承認」）で年額／月額を購入し、以下を確認：
   - 購入直後にロックが即解除される（`sync-subscription`＋Webhook）
   - パートナー端末でも追加課金なしで「パートナーのプランで解放済み！」と表示される
   - 過去の未回答お題への追っかけ回答・AI相性診断レポート生成が成功する
   - 再インストールまたは別端末ログイン時に「以前の購入を復元する」で復元される（未契約アカウントでは「有効なご契約が見つかりませんでした」と表示される）

## 4. データセーフティ（Data Safety）回答シート

| アカウント削除を行わずにデータ削除をリクエストする方法を提供していますか？ | **いいえ**（アカウント単位で全データ削除＋180日非アクティブ自動削除） |

### 収集するデータタイプ一覧（共有：すべて「いいえ」＝広告・第三者販売なし）
| カテゴリ | データタイプ | 収集 | 共有 | 必須 / 任意 | 利用目的 |
|---|---|---|---|---|---|

| 財務情報 | **購入履歴**（サブスク契約状態・商品ID・有効期限） | はい | いいえ | 任意（課金時のみ） | アプリの機能、アカウント管理 |

- **AI 生成コンテンツのポリシー（該当欄が表示された場合）**:
  - AI 機能は有料ユーザー向けに二人のスワイプ選択結果のみから定型 JSON レポートを生成するもので、自由テキストチャットや画像生成は含みません。不適切な表現や責める表現を抑止するシステム指示を適用済みです。

## 6. 14日間クローズドテスト（個人アカウント必須要件）運用ガイド

2023年11月以降に作成された個人 Google Play デベロッパーアカウントでは、本番公開申請の前に以下の条件を満たす必要があります：

1. **本番用 AAB をビルド**
   ```bash
   npx eas-cli@latest build --platform android --profile production
   ```
2. **クローズドテストトラックを作成**し、AAB をアップロードして審査を通過させる
3. **テスター 12名以上** の Google アカウント（Gmail）をメーリングリスト／Google グループに登録し、オプトイン URL からテスト参加してもらう
