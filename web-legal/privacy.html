プライバシーポリシー

最終改定日: 2026年11月23日 ／ 対象アプリ: Kotaeai（com.garanapop.coupleswipeapp）

本プライバシーポリシーは、アプリ「Kotaeai」（以下「本アプリ」）におけるユーザー情報の取り扱いについて定めるものです。

1. 取得する情報

  • アカウント識別子：匿名認証により自動発行されるユーザーID。機種変更引き継ぎのために Google アカウント連携を行った場合のみ、Google アカウントのメールアドレス・認証識別子を取得します。
  • ユーザーが入力する情報：表示名（ニックネーム）、ペア招待コード、日々の質問に対する選択方向（上下左右）の回答履歴。
  • 通知用トークン：パートナーの回答完了通知を配信するための Expo Push Token（プッシュ通知を許可した端末のみ）。
  • 課金ステータス情報：有料プラン（「ふたりプレミアムプラン」）の契約状態・有効期限・商品識別子（決済カード情報自体は Google Play が処理し、本アプリでは保持しません）。

2. 利用目的

  • ペア間の出題同期、双方回答完了後の結果公開、および過去の回答比較機能の提供
  • パートナーの回答通知の配信
  • 有料プラン加入ペアに対する AI 相性レポートの生成・表示
  • 機種変更時のデータ引き継ぎ、不正利用防止（招待コード試行制限・レート制限）

3. 第三者提供・外部サービスの利用

本アプリは機能提供のため、以下の信頼できる外部サービスを利用しています。法令に基づく場合を除き、ユーザーデータを広告目的で販売・提供することはありません。

  • Supabase（データベース・認証・サーバー処理）
  • Expo / Firebase Cloud Messaging (FCM)（プッシュ通知配信）
  • Google Play Billing / RevenueCat（サブスクリプション決済および購入状態の検証）
  • Google Gemini API（有料プラン加入ペアが AI 相性レポート生成を実行した場合に限り、回答履歴テキストを分析のために送信します。無料ユーザーのデータは AI API へ送信されません）

4. データの保管期間と自動削除

  • 長期間利用されていないペアデータ（最終利用から180日以上経過）は、自動的にデータベースから削除されます。
  • ユーザーはアプリ内または Web ページからいつでも即時にアカウントおよび関連データを削除できます。詳しくは アカウント・データ削除のご案内 をご覧ください。

5. 安全管理措置

通信はすべて HTTPS (TLS) により暗号化され、データベースには Row Level Security (RLS) を適用し、所属ペア以外の第三者および回答完了前の相手から回答内容を参照できないアクセス制御を行っています。

6. お問い合わせ

本ポリシーやデータの取り扱いに関するお問い合わせは、Google Play ストア掲載のデベロッパー連絡先、または GitHub リポジトリ（garana-pop/couple-swipe-app）よりご連絡ください。
