# ふたりスワイプ（二人同時4択スワイプ相性診断アプリ）

カップル向けの「二人同時4択スワイプ相性診断」モバイルアプリです。
1日3問の質問に上下左右のスワイプで回答し、双方が回答完了して初めて一致率と相手の答えがオープンになります。

---

## 📱 主な機能（MVP構成）

1. **初回起動時ウォークスルー・チュートリアル**
   - 初回起動時に自動で立ち上がる3ステップの操作ガイドモーダル
   - 4方向（↑上・↓下・←左・→右）のスワイプ操作が直感的にわかる図解ダイアグラム
   - ハンバーガーメニューからいつでも再確認可能

2. **ホーム／ペア連携画面 (`/`)**
   - 招待コードの共有・入力UI
   - パートナー連携状態の可視化
   - 「今日の質問へ進む」動的アクション（未回答／待機中／結果確認のステータス連動）
   - **ヘッダーのハンバーガーメニュー（☰）**:
     - 過去の回答との比較タイムライン
     - 二人の相性レポート（AI診断・プレミアム）
     - アプリの使い方チュートリアル
     - 招待コードの共有
     - 動作確認用初期リセット

3. **今日の質問スワイプ画面 (`/quiz`)**
   - 上下左右の4方向スワイプカード（`PanResponder` + `Animated` による滑らかな操作）
   - ドラッグ方向に連動したカード枠線＆カード内背景色の淡いカラー変化
   - 奥行きと厚みを持たせた立体スロット（トレイ）とカードスタック（奥のカード影）
   - 過去に出題歴のある質問には「90日ぶりの質問」などのリピートバッジを表示

4. **回答ロック・待機画面 (`/waiting`)**
   - 相手が未回答の間、相手の答えを完全に伏せるロックUI
   - パルスアニメーションによる待機演出
   - **【動作確認用】相手の回答完了シミュレートボタン**（押すだけで即座にロック解除）

5. **一致率・結果画面 (`/result`)**
   - 双方回答完了時のみ閲覧可能（未完了時は自動ロック画面へ誘導）
   - シンプルな一致率サークル表示（%）
   - 質問ごとの回答対比一覧（自分の回答、相手の回答、一致／不一致バッジ）
   - **過去との回答比較セクション**:
     - 一定期間後に再出題された質問について、前回（例: 3ヶ月前）と今回の二人の回答の変化を対比表示

6. **質問の比較タイムライン画面 (`/history`)**
   - ハンバーガーメニューからアクセス可能
   - 出題履歴と二人の回答の推移・変化のメモを一覧で確認

7. **二人の相性レポート画面 (`/ai-report`)**
   - ハンバーガーメニュー内に控えめに格納
   - AI性格タイプ分析（「計画派リーダー × 柔軟な癒やしマイペース」）
   - 潜在的リスクとAIのアドバイス
   - ペア片方課金で2人とも見放題になるサブスクリプション料金モック

## 🚀 ローカル起動確認手順

### 1. 開発サーバーの起動

```bash
npx expo start
```

またはクリアキャッシュで起動する場合:
```bash
npx expo start -c
```

### 2. 各プラットフォームでの確認方法

- **Android実機 / Expo Go で確認する場合**:
  1. Google Play から「Expo Go」アプリをスマホにインストールします。
  2. ターミナルに表示された QR コードを Expo Go（またはカメラアプリ）でスキャンします。
  3. ※ PCとスマホが同一の Wi-Fi ネットワークに接続されている必要があります。
     （接続が難しい場合は `npx expo start --tunnel` を利用してください）

- **Androidエミュレータで確認する場合**:
  - ターミナルで `a` キーを押すと Android エミュレータが起動します。

- **Webブラウザで手軽にUI確認する場合**:
  - ターミナルで `w` キーを押すか、`npm run web` でブラウザ上でプレビューできます。

### 3. 品質チェックコマンド

```bash
# 型チェック
npm run typecheck   # または npx tsc --noEmit

# リントチェック
npm run lint        # または npx expo lint
```
