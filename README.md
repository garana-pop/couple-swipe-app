# Kotaeai（コタエアイ）— 二人同時4択スワイプ価値観診断アプリ

カップル・夫婦向けの「二人同時4択スワイプ価値観診断」モバイルアプリ（Expo / React Native + Supabase）です。
1日3問の質問に上下左右の4方向スワイプで直感回答し、お互いが回答を完了して初めて一致率と相手の答えがひらきます。回答カレンダーで回答済み・未回答の日をひと目で管理でき、プレミアムプランでは過去の未回答日へ遡って回答したり、深層 AI 相性診断レポートを楽しめます。

---

## 📱 主な機能

1. **初回起動時ウォークスルー・チュートリアル**
   - 初回起動時に自動で表示される3ステップの操作ガイドモーダル
   - 4方向（↑上・↓下・←左・→右）のスワイプ操作と秘密ロック、回答カレンダー・過去比較の仕組みをわかりやすく案内
   - ハンバーガーメニューからいつでも再確認可能

2. **ホーム／ペア連携画面 (`/`)**
   - 招待コードの発行・共有・入力によるペアリング（Supabase 同期）
   - 連続回答ストリーク・自身の未回答日数・通算一致率のステータスバー
   - 「今日の質問へ進む」動的アクション（未回答／相手の回答待ち／結果確認のステータス連動）
   - 過去の未回答日がある場合は、回答カレンダー確認・プレミアム遡り回答への導線カードを表示
   - **ヘッダーのハンバーガーメニュー（☰）**:
     - 過去の回答との比較（回答カレンダー・出題履歴）
     - AI相性診断・プレミアム
     - 通知・アカウント引き継ぎ（Google 連携）
     - アプリの使い方チュートリアル
     - 招待コードの共有・ペア解除・アカウント削除

3. **質問スワイプ画面 (`/quiz`)**
   - 上下左右の4方向スワイプカード（`PanResponder` + `Animated` による滑らかな操作）
   - 当日のお題だけでなく、プレミアム加入ペアは過去日の未回答お題（`?date=YYYY-MM-DD`）へも遡って回答可能
   - 過去に出題歴のある質問には「○日ぶりの質問」リピートバッジを表示

4. **回答ロック・待機画面 (`/waiting`)**
   - 当日のお題は双方が完了するまで相手の答えを完全に伏せるロック UI（Supabase RLS で保護）
   - パルスアニメーションと自動ポーリングによるリアルタイム待機

5. **一致率・結果画面 (`/result`)**
   - 双方回答完了時（および過去日完了時）に一致率サークル・質問ごとの回答対比・不一致時の会話きっかけを表示
   - 再出題質問の前回との回答変化比較
   - SNS・LINE 共有用のプライバシー配慮「一致率カード」モーダル

6. **質問の比較・回答カレンダー画面 (`/history`)**
   - 連続ストリーク・自身の未回答日数・通算一致率・カテゴリ別一致率グラフ
   - **回答カレンダーモーダル**: 月ごとに双方完了／自分のみ回答済み／今日未回答／過去未回答（パートナー回答済みマーク付き）を一覧表示
   - カレンダー内の未回答日をタップすると、プレミアム加入ペアはそのまま遡って回答可能（未加入ペアにはプレミアム案内を表示）
   - 今日のお題（前回との比較）と過去の履歴タイムライン

7. **ふたりプレミアム・AI相性診断レポート画面 (`/ai-report`)**
   - ペアのどちらか1人の加入（年額／月額）で2人とも利用可能（Google Play Billing + RevenueCat + Supabase 同期）
   - 回答カレンダーからの過去日遡り回答＆ネタバレ防止付きの結果解放
   - Gemini API による深層 AI 相性診断レポート・過去レポートアーカイブ・すれ違い／別れの原因の優しい AI 振り返り診断

8. **通知・アカウント設定画面 (`/settings`)**
   - 毎日の質問リマインダー（ローカル通知）とパートナー回答完了プッシュ通知
   - 匿名アカウントからの Google アカウント連携（機種変更引き継ぎ）

## 🚀 ローカル起動確認手順

### 1. 開発サーバーの起動

```bash
npx expo start
```

クリアキャッシュで起動する場合:
```bash
npx expo start -c
```

### 2. 品質チェックコマンド

```bash
# 型チェック
npm run typecheck   # または npx tsc --noEmit

# リントチェック
npm run lint        # または npx expo lint
```
